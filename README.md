# Для тестування коду виконайти наступні кроки:
1. git clone https://github.com/MisterDenix/LinearProgrammingGraphicalMethod.git
2. Впевніться, що ви знаходитесь у потрібно віртуальному середовищі venv. Якщо попереду командого рядка видно в дужках (.venv) перейдіть до кроку 3.
* 2.1 Якщо у вас Windows зробіть віртуальне середовище командою **python -m venv .venv**
* 2.1 Активуйте середовище командою .\.venv\Scripts\activate
3. **pip install -r requirements.txt**

4. Запускайте код! Через редактор або командою **python main.py**
